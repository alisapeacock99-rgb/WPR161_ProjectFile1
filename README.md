# Book Empire – Online Book Discovery Website

## Overview

**Book Empire** is a front-end web development project designed to provide users with an engaging platform for exploring a wide variety of books, including novels, manga, fiction, and other literary genres. The website focuses on delivering a user-friendly browsing experience through an intuitive interface, visually appealing layouts, and easy navigation between pages.

The project was developed using **HTML, CSS, and JavaScript** and demonstrates core web development concepts such as responsive design, page navigation, interactive elements, and user-focused content organization.

---

## Features

### 📚 Book Exploration

* Browse a collection of books from different genres.
* Visually appealing book displays and layouts.
* Easy navigation through featured content.

### 🏠 Homepage

* Welcoming landing page introducing Book Empire.
* Navigation menu linking to all major sections.
* Attractive design with images and book showcases.

### 📄 Terms of Service

* Dedicated Terms of Service page outlining website usage policies.
* Users can choose to accept or decline the agreement.
* Redirection functionality based on user selection.

### ❓ Frequently Asked Questions (FAQ)

* Interactive FAQ section.
* Expandable and collapsible questions using JavaScript.
* Provides answers to common user inquiries.

### 🎨 Modern User Interface

* Custom CSS styling.
* Responsive page layouts.
* Consistent design across all pages.
* Google Fonts integration for improved typography.

## Website Workflow

### 1. Landing Page

Users are welcomed to Book Empire and introduced to the purpose of the website.

### 2. Homepage

Users can browse available content and navigate through different sections of the website.

### 3. Terms of Service

Before proceeding, users can review the website's Terms of Service.

### 4. User Decision

* **Accept Terms:** Continue using the website.
* **Decline Terms:** Redirected to a page explaining that access requires agreement to the Terms of Service.

### 5. FAQ Section

Users can access answers to commonly asked questions through an interactive FAQ page.
